제출 자료·제출처·결재 기준 · 원문 15쪽

3~4월

계획 단계

  1. 학교 실태와 연구과제 확인

    학생·교원·학부모의 요구와 교육과정 운영 여건을 살펴 과제와 세부 목표를 정합니다.

  2. 운영 조직과 협의체 구성

    학교 내부 역할과 협의 일정을 정하고 안건을 공유합니다. 협의 결과를 운영계획서와 예산 계획에 반영합니다.

  3. 계획서와 제출 자료 준비

    운영계획서 초안·수정본, 예정자 명단, 협의체 위원 명단, 지원금 집행 계획서를 준비합니다. 누리집 게시 자료는 공개 전에 점검합니다.

운영계획서 쓰기 협의회 서식 계획 체크리스트

계획 단계 원문 17~18쪽

5~8월

실행 단계

  1. 수업과 교육활동에 연구과제 적용

    과제별로 수업·학생 참여 활동을 진행하고 운영 일정에 맞춰 실행 정도를 점검합니다.

  2. 시범수업과 수업 후 협의

    수업자와 교수·학습과정안을 정하고, 수업 뒤 학생 반응과 개선점을 협의해 다음 운영에 반영합니다.

  3. 과제별로 자료 축적

    수업안, 학생 산출물, 설문·관찰 기록, 협의 결과를 모읍니다. 자료마다 과제, 생성 날짜와 사용 목적을 함께 기록합니다.

공개수업 준비 실행 체크리스트

실행 단계 원문 19~20쪽

9~11월

보고·평가 단계

9~10월 · 행사 준비

수업 나눔의 날 일정과 방식, 수업자와 참관 대상을 정하고 관련 자료를 준비합니다.

10~11월 · 보고서 작성

실행 자료와 사전·사후 변화 분석을 바탕으로 최종보고서와 일반화 자료를 작성해 협의에서 검토합니다.

수업 나눔의 날

수업안, 운영 개요와 안내 자료를 준비합니다. 당일에는 참관 안내, 수업, 질의응답과 협의를 진행하고, 학생의 변화와 적용 사례를 공유합니다. 협의에서 나온 의견은 최종보고서와 일반화 자료에 반영합니다.

공개수업 준비누리집 게시 시기

11월 · 평가와 최종 제출

최종보고서, 일반화 자료, 운영 평가표, 지원금 최종 결산 보고서를 점검합니다. 일반화 자료에는 다른 학교에서 적용할 수업 모형, 교수·학습 자료와 활용 방법을 담습니다.

최종보고서 쓰기지원금 결산 서식보고·평가 체크리스트

보고·평가 단계 원문 21~23쪽

이듬해 2월까지

후속 운영과 자료 정리

수업 나눔의 날 이후에도 운영을 지속하고, 보고서와 일반화 자료의 최종본, 협의 결과와 평가 자료를 보관합니다. 후속 연구나 학교 교육과정 개선에 반영할 내용과 새 담당자에게 넘길 업무를 정리합니다.
